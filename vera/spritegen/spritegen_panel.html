Import sprite sheets — PNG / ZIP, no GPU

      

        PNG sheet → one animation of the selected character (new character if none picked).
        Grid auto-detects from transparent gutters / square cells — or set it below.
        Solid backgrounds are keyed out automatically. ZIP → whole character
        (exported Character.zip or any folder of sheet PNGs + optional atlas .json).
        Imported animations are auto-aligned onto one shared cell so switching between
        them doesn't shift the character.

Image → sprite — convert any picture into a sprite frame

      
Photo, artwork or AI render → background removed (rembg tier → corner-colour key fallback) → pixelized to the character's sprite size and palette. Lands as one frame of the chosen animation — open it in Draw to touch up or extend into a cycle.

Controls & Buddy — bind ANY animation to activities, keys & tamagotchi behaviour

      
save a definition and build at least one animation first.

      

        
Activity slots

        
Which animation plays for each activity — the chat buddy reacts with these. Leave a slot on “default” to fall back automatically (e.g. think→idle). move/run drive walking; the rest are moods/actions you can map however you like.

        


        
Action keys

        
Press a key → play an animation once. The number of moves is the number of keys/combos you bind. Use Space for the spacebar.

        

        

        
Movement keys

        
Comma-separated keys per direction (defaults shown). The sprite flips for left/right and plays the move/run slot.

        


        
Tamagotchi

        
When idle for a while the buddy acts on its own — wanders around, plays a random emote, or rests.
