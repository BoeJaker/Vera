WEB API PROVIDERS
Register a platform's own API here and Vera's web search & fetch will automatically use it instead of scraping — cleanest for sites that hard-block crawlers (Reddit above all). A provider claims one or more domains (any fetch of those hosts is served by the API) and optional trigger keywords (a web search containing one, or a site: filter, runs the platform's own search first). Credentials are sealed in Vera's vault.
