Vera ↔ Claude Code MCP bridge

Installing the bridge lets a remote Claude Code session call back into Vera — record work, query memory, run Vera IDE tools — i.e. use the Vera IDE features from VS Code. It deploys ~/.vera/vera_mcp_bridge.py, runs claude mcp add vera …, and writes <workdir>/.mcp.json.

VS Code extension

A companion extension lives in tools/vera-vscode/. Build it with npm install && npx vsce package and install the resulting .vsix in any VS Code / code-server instance. It adds a Vera sidebar (memory search, enqueue tasks) and a “Vera: Connect this workspace” command that installs the MCP bridge locally.
