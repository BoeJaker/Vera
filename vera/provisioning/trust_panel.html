Why isn't there a one-click "trust" button? Browsers deliberately forbid any web page from installing a root CA into your trust store — otherwise a malicious site could forge trust for every other site. So the CA has to be imported by you, once. The steps below take about 30 seconds.

Windows Chrome, Edge, other Chromium

  1. Click Download CA certificate above (saves vera-freeipa-ca.crt).
  2. Double-click the file → Install Certificate… → Current User → Next → Place all certificates in the following store → Browse → Trusted Root Certification Authorities → OK → Next → Finish → Yes.
  3. Fully quit and reopen your browser, then reload this page.

…or, no clicking through the wizard — run this in PowerShell (no admin needed) after downloading:

Import-Certificate -FilePath "$env:USERPROFILE\Downloads\vera-freeipa-ca.crt" -CertStoreLocation Cert:\CurrentUser\Root

Firefox separate trust store

Firefox ignores the OS store and keeps its own.

  1. Download the CA above.
  2. Open about:preferences#privacy → scroll to Certificates → View Certificates… → Authorities tab → Import….
  3. Pick vera-freeipa-ca.crt, and tick “Trust this CA to identify websites.” → OK.
  4. Reload this page (no restart needed).

macOS Safari, Chrome, Edge

  1. Download the CA above, then double-click it → it opens in Keychain Access (add to the login keychain).
  2. Find “Certificate Authority” in Keychain Access → double-click → expand Trust → set “When using this certificate: Always Trust.”
  3. Close (enter your password to save) and reload. Firefox on macOS uses its own store — see the Firefox tab.

Linux system + Chrome

sudo cp vera-freeipa-ca.crt /usr/local/share/ca-certificates/vera-freeipa-ca.crt
sudo update-ca-certificates

Chrome/Chromium may also need it in the NSS store: certutil -d sql:$HOME/.pki/nssdb -A -t "C,," -n "Vera FreeIPA CA" -i vera-freeipa-ca.crt. Firefox: use the Firefox tab.
