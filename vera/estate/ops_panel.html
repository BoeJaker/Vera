Pipes

Runs follow each plane's own lanes. Between planes a run leaves by its plane's bus point on the front edge, rises or falls on a riser outside every plate, and wears its origin plane's colour. Selecting a node lifts everything it is wired to.

Widgets▾

A node carries several widgets: a server for a machine, and its readings — a dial for its load, a thermometer, a tank for its disk — each joined to the node on the plane. Select a node and press ⊕ to add one; the size button steps ×¾ · ×1 · ×1.3; ✕ takes one off.
