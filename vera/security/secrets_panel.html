Where stored secrets are kept

Everything Vera seals goes to OpenBao. Older values sealed with the file key can be moved; OpenBao's own unseal key and token always stay with the file key, because they open it.

Named secrets

Secrets other parts of Vera ask for by name, such as the netctl door token or a Platforms credential. Hand one to keydrop to get it into KeePass.

SSH logins

Repeats of the same login are folded into one, a password login beside a key login for the same host is dropped, and so is a login whose host no longer answers and matches no machine. A login anything else refers to always stays, and every login is backed up into OpenBao before a change.
