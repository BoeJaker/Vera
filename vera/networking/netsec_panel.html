Encrypted overlay across the cluster. Pulls Proxmox nodes, guests and Docker hosts onto a private, authenticated network so Vera's connections ride encrypted links between enrolled devices. Tolerant to begin: hosts can join before they're enrolled (turn on Enforce enrolment to refuse non-enrolled hosts). Keys are generated on each host and never leave it. Enrol hosts in Provision → Enroll; deploy step-ca first from Provision → Security.
