v6/v7 — adaptive control · failure recovery / branching
Each step gets a checkable success criterion. After every step a controller reads the shared ledger and continues, inserts a fix, replans, or stops early once the goal is met — then a final gate verifies the whole goal. The On step fail control below is the branching-vs-error-correction choice (extra step / branch / default).
v7 — clarify · comms · long-horizon
Ask steering questions before/along a plan, report progress over comms, and gather only the info a step is missing. Strategic (multi-day) goals persist to the Dream system and appear in 🎯 Goals.
Context fidelity
Several stages REWRITE run material with an LLM before another stage reads it. Each is useful alone, but together a step can end up reading a summary of a summary. Turn them off to make the loop pass through what actually happened.
Piecewise planning (strategic goals)
The cap-agnostic master planner drafts a long-form strategy; piecewise planning splits it into ordered phases (each suggesting its own caps), then runs ONE phase per session — the rest defer to the Dream system.
